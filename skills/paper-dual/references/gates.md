# 门禁与验收矩阵

## 段级门禁（lint 逐段判定，任一失败即拒该段）

| 门禁 | 判据 | 失败后果 |
| --- | --- | --- |
| 锁定区 | pid 属于标题/表格/代码/公式/脚注/域/引用链接/图形/参考文献/附录/混合格式/制表换行/过短 | 该段拒绝 |
| 任务范围 | pid 不在本轮任务清单内 | 该段拒绝 |
| 实体 | 数字（含小数/百分号）、引用 `[n]`、书名《…》、缩写（≥2 大写字母）的集合与原文完全一致 | 该段拒绝 |
| 主观表述 | 「我觉得/我认为/笔者觉得/个人认为/我们觉得」计数不得增加 | 该段拒绝 |
| 长度 | 改写后字数 ∈ 原文 × [0.55, 1.40]（去空白计字） | 该段拒绝 |
| 语义代理 | 字二元组重合度 ≥ 0.30，且否定词计数守恒 | 该段拒绝 |
| 算子 | op ∈ O1–O9 | 该段拒绝 |

语义代理是**代理指标**（字二元组 + 否定守恒），不是句向量；深层语义反转可能漏检，作者复核不可省。

## 篇级复检（finish 回填后，任一失败整篇回退）

- 段落数量不变；每段格式签名（段落属性 + 字符属性 + 结构，文本置空后的规范 XML）不变。
- 锁定段文本逐字不变。
- 按模式验收指标（基线为 0 时只要求不恶化）：
  - `dedup`：篇内重复率严格下降。
  - `aigc`：痕迹风险总分严格下降，且高风险段数不上升。
  - `dual`：以上两者同时满足。
- 失败时：被拒改稿留档 `rounds/rN/rejected.docx`，基础稿保持上一版已验收稿（无则原文），绝不悄悄留下更差的稿。

## 任务派发阈值

- 痕迹风险分：高 ≥ 6，中 ≥ 3，低 < 3（9 维加权，单维贡献封顶 ×2）。
- 篇内重复：13 字指纹在 ≥2 个可改写段出现即计重复；单段重复占比 ≥ 20% 入任务，≥ 45% 派 O9。
- 每轮任务上限：双降/降重 16/10/6/4/2，降 AI 12/8/5/3/2；硬上限五改。

## 格式保形写入

回填只对原始 `word/document.xml` 做段落级文本外科手术：新文本写入该段第一个 `w:t`，其余 `w:t` 置空，段落属性与字符属性不动；zip 内其他条目逐字节复制。写入前做段落定位校验（数量与文本对齐），含文本框等嵌套结构导致无法安全定位时**放弃写入**并报错，保护原件。混合格式段在诊断阶段即排除，不参与改写。
