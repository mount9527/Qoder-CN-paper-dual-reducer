# 门禁与验收矩阵

## 段级门禁（lint 逐段判定，任一失败即拒该段）

| 门禁 | 判据 | 失败后果 |
| --- | --- | --- |
| 锁定区 | pid 属于标题/表格/代码/公式/脚注/域/引用链接/图形/参考文献/附录/混合格式/制表换行/过短/未知样式 | 该段拒绝 |
| 任务范围 | pid 不在本轮任务清单内 | 该段拒绝 |
| 实体 | 数字（含小数/百分号）、引用 `[n]`、书名《…》、缩写（≥2 大写字母）及各自出现次数与原文完全一致 | 该段拒绝 |
| 主观表述 | 「我觉得/我认为/笔者觉得/个人认为/我们觉得」计数不得增加 | 该段拒绝 |
| 长度 | 改写后字数 ∈ 原文 × [0.55, 1.40]（去空白计字） | 该段拒绝 |
| 语义代理 | 字二元组重合度 ≥ 0.40，且不得增删显式否定表述 | 该段拒绝 |
| 算子 | op ∈ O1–O9 | 该段拒绝 |

语义代理是**代理指标**（字二元组 + 显式否定检查），不是句向量；深层语义反转仍可能漏检，作者复核不可省。

## 任务覆盖与部分完成

- `lint` 会把本轮未提交的任务段列为「任务覆盖」拒绝；`finish` 默认要求全部任务提交并通过，且清单不得含非法行或范围外改写。
- 无法修正的段必须先取得用户明确确认，才能使用 `finish --allow-partial`（MCP 工具为 `allowPartial:true`，工作台为勾选「允许部分完成」）。
- 部分完成只跳过被拒或未提交段；非法 JSONL 行仍会导致整轮拒绝。验收通过的轮次标记 `partial:true`，报告与工作台显示「部分通过」。
- 无论整轮通过还是部分通过，篇级复检与指标验收规则都相同；失败仍整篇回退。
- `lint` 预检失败时退出码为 2；`finish` 未通过或拒绝时也返回 2，避免 `lint && finish` 误继续。

## 篇级复检（finish 回填后，任一失败整篇回退）

- 段落数量不变；每段格式签名（段落属性 + 字符属性 + 结构，文本置空后的规范 XML）不变。
- 锁定段文本逐字不变。
- 按模式验收指标：
  - `dedup`：篇内重复率上升不超过 0.002（0.2 个百分点）即通过；下降更好。
  - `aigc`：痕迹风险总分不上升，且高分段段数不上升；持平可通过。
  - `dual`：以上两者同时满足。
- 三态语义：`passed`=本地门禁通过；`not_passed`=候选稿已生成但篇级复检/指标未过，已回退；`rejected`=输入或任务集不合格，未回填，基础稿不变。三者都不表示平台通过概率。
- 失败时：被拒改稿留档 `rounds/rN/rejected.docx`，基础稿保持上一版已验收稿（无则原文），绝不悄悄留下更差的稿。

## 任务派发阈值

- 痕迹风险分：高 ≥ 6，中 ≥ 3，低 < 3（9 维加权，单维贡献封顶 ×2）。
- 篇内重复：13 字指纹在 ≥2 个可改写段出现即计重复；单段重复占比 ≥ 20% 入任务，≥ 45% 派 O9。
- 每轮任务上限：双降/降重 16/10/6/4/2，降 AI 12/8/5/3/2；硬上限五改。

## 格式保形写入

回填只对原始 `word/document.xml` 做段落级文本外科手术：新文本写入该段第一个 `w:t`，其余 `w:t` 置空，段落属性与字符属性不动；zip 内其他条目逐字节复制。写入前做段落定位校验（数量与文本对齐），含文本框等嵌套结构导致无法安全定位时**放弃写入**并报错，保护原件。混合格式段与含 `w:smartTag`/`w:customXml`/`w:sdt` 的嵌套文本容器在诊断阶段即排除，不参与改写。仅在新文本首尾需要保留空白时补充 `xml:space`，格式签名校验忽略该空白保留属性。
